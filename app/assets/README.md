# Assets

## `title_block_a3.pdf` - Arete A3 title block (blank)

The office A3 landscape sheet (1190.55 x 841.89 pt): border, Arete logo and company details,
and a title block across the bottom with fillable form fields. Stored for future use on the
mark-up sheets - not yet used by the app.

- Drawing area (inside the border): about x 28-1162, y 28-716 pt; the title block is below it
  (y 716-830).
- Form fields (35, all text), placeholder value in brackets:
  - `CLIENT` (CLIENT), `PROJECT NUMBER` (PROJECT), `PROJECT TITLE` (PROJECT TITLE), `ADDRESS` (ADDRESS)
  - `DRAWING TITLE 1` (DRAWING TITLE 1), `DRAWING TITLE 2` (SHEET 1)
  - `SHEET NUMBER` (DRAWING) - drawing no., `SHEET REVISION` (REVISION), `SHEET DATE` (DATE),
    `DRAWING STATUS` (DRAWING STATUS)
  - `DESIGNED BY`, `APPROVED BY`, `DRAWN BY`, `CHECKED BY`
  - Issue table, rows 1-7: `ISSUE REVISION - n` (REV n), `ISSUE DESCRIPTION - n` (DESCRIPTION),
    `ISSUE DATE - n` (DATE)
- Sheet size (A3) is printed, not a field.
